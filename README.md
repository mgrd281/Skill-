# دليل أدوات التصميم والتطوير

صفحة ويب واحدة تجمع أكثر من 160 أداة ومهارة لـ Claude: التصميم، والهوية، والأنيميشن، والموشن غرافيك، والمتاجر والتسويق، والبرمجة والأمان، وiPhone وMac، وVercel، وفحص المواقع، والفواتير والمحاسبة.

## المزايا

- **ماذا تبني؟** اختر نوع مشروعك لترى الأدوات المناسبة ونصيحة البداية.
- لكل أداة: وصف بالعربي، والمشاريع التي تفيدها، ونجوم GitHub، وأمر التثبيت مع زر نسخ.
- روابط منفصلة لـ GitHub وللموقع الرسمي.
- بحث، وتصفية حسب القسم، و"المهارات فقط"، و"الجديد فقط"، وترتيب حسب النجوم.
- يعمل على الجوال، وبالوضعين الفاتح والداكن.

## التشغيل

افتح الملف `index.html` في المتصفح. لا يحتاج أي تثبيت أو خادم.

## النشر على GitHub Pages

1. ارفع الملفات إلى مستودع جديد على GitHub.
2. افتح **Settings** ثم **Pages**.
3. اختر الفرع `main` والمجلد `/ (root)` ثم احفظ.
4. بعد دقيقة تقريبًا تصبح الصفحة متاحة على رابط مثل `https://USERNAME.github.io/REPO/`.

## تحديث البيانات

كل الأدوات موجودة في المصفوفة `T` داخل `index.html`. كل سطر بهذا الترتيب:

```
[القسم, الاسم, النوع, جديد (0 أو 1), رابط GitHub, الموقع, النجوم, أمر التثبيت, [المشاريع], الوصف]
```
