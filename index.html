دليل أدوات التصميم والتطوير

أدوات مرتبة حسب القسم، ولكل أداة وصف قصير، والمشاريع التي تفيدها، وأمر التثبيت، ورابط GitHub والموقع الرسمي.

  • Skill تعليمات تضيفها إلى Claude
  • MCP يربط Claude بأداة خارجية
  • مكتبة تُستخدم داخل كود الموقع
  • جديد من الإضافات المقترحة
  • ابدأ بها أفضل بداية للمشروع المختار

ماذا تبني؟

اختر نوع مشروعك لترى الأدوات المفيدة له ونصيحة البداية.

النجوم وروابط المواقع مأخوذة من صفحة كل مشروع على GitHub بتاريخ 17 أكتوبر 2026. مهارات Anthropic الأربع تعرض نجوم المستودع الذي يجمعها.

أوامر /plugin تُكتب داخل Claude Code. أوامر npx وnpm وflutter وdocker تُكتب في الطرفية داخل مجلد مشروعك.

لاكتشاف مهارات أخرى: skills.sh يرتّبها حسب عدد التثبيت ويعرض فحصًا أمنيًا لكل مهارة، وclaudemarketplaces.com يرتّبها حسب القسم. المهارة قد تشغّل أوامر على جهازك، فثبّت من مصادر معروفة فقط.

رخص مجموعات الأيقونات والمكونات تختلف، وشعارات العلامات التجارية تبقى ملكًا لأصحابها. اقرأ الرخصة قبل الاستخدام التجاري.

استثناءات: روابط Remotion Skills وflutter_animate وShopify Dev MCP من التوثيق الرسمي، وAceternity UI موقع فقط بدون مستودع.
